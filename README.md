# SYFO Landing Page Clone

A simple **Next.js + Tailwind CSS** landing page, replicating the design and layout of the SYFO website. Built to practice responsive design, component-based architecture, and modern frontend workflows.

### Key Features

- Hero section highlighting the main product or service.  
- Features and reference sections for content display.  
- Fully responsive layout using **Tailwind CSS**.  
- Modular component structure for maintainability and scalability.  
- Clean and modern design, suitable as a learning project for frontend development.
